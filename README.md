# Projeto Calculadora
Curso Analista de Dados na EBAC

## Como executar O Arquivo calculadora.sh

 - Abra o aplicativo Ubuntu
 - Vá na pasta do Arquvio
 - Dê a permissão da execução do arquivo:
 - chmod 744 calculadora.sh
 - Agora execute o arquivo:
 - ./calculadora.sh

## Como executar O Arquivo calculadora.py
 - Abra o aplicativo Ubuntu
 - execute o arquivo:
 - python3 calculadora.py

## Explicação do codigo python

 - Código que recebe dois números de entrada, lhe mostra opções de somas e o resultado dos números inseridos.
